**The roast:** *The fridge's camera took a photo of my rotting lettuce and sent me a notification: 'We need to talk.'*

One line roasting a smart fridge: its camera photographs the rotting
lettuce and stages a breakup intervention over it.

## Run

```sh
node main.ts
```

Writes `entry.txt` (101 characters, one line, no trailing newline) to
`/output` (or `$MAKEFUN_OUTPUT_DIR`). Deterministic: no clock, no
network, no randomness — two runs produce byte-identical output. The
program gate-checks the 1–200 character rule itself and reads the file
back to prove the shipped bytes are exactly the roast.
